# TrustBridge FE — embedded client

Device-side firmware client. Runs on supported Sandgrain gateways and host SDKs, performs enrollment with biometric attestation, and streams encrypted telemetry to `TrustBridge BE`.

* Version: **3.2.0**
* Stream:  `release/v3.2.0`
* Depends on: `@sandgrain/trustbridge-sdk@3.2.x`
