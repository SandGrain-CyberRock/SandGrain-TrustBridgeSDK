# TrustBridge FE — embedded client

Device-side firmware client. Runs on supported Sandgrain gateways, performs enrollment and attested handshake against `TrustBridge BE`, and streams encrypted telemetry.

* Version: **3.1.0**
* Stream:  `release/v3.1.0`
* Depends on: `@sandgrain/trustbridge-sdk@3.1.x`
