# TrustBridge FE — embedded client

Device-side firmware client. Runs on supported Sandgrain gateways and host SDKs, performs enrollment with biometric attestation, propagates OpenTelemetry trace context, and streams encrypted telemetry to `TrustBridge BE` with backpressure.

* Version: **3.3.0**
* Stream:  `release/v3.3.0`
* Depends on: `@sandgrain/trustbridge-sdk@3.3.x`
