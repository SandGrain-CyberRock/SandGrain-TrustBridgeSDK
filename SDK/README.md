# SDK — TrustBridge core library

Shared protocol and crypto library used by both `TrustBridge FE` and `TrustBridge BE`. This package defines the v3 handshake, session lifecycle, biometric auth helpers, the BE session pool, and OpenTelemetry trace propagation.

* Version: **3.3.0**
* Stream:  `release/v3.3.0`
