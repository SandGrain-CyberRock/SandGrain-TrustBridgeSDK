# SDK — TrustBridge core library

Shared protocol and crypto library used by both `TrustBridge FE` and `TrustBridge BE`. The v3.4 development line adds Gateway v4 protocol support, post-quantum attestation (Dilithium), and a WebAssembly build target.

* Version: **3.4.0-dev**
* Branch:  `development/v3.4.0`
